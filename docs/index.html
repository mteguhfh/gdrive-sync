gdrive-sync

Back up selected folders from a Linux laptop to Google Drive with rclone and a systemd user timer. No daemon, no cloud service, no account on our side.

Source code on GitHub

What it does

  • One-way backup, one-way mirror, or two-way bisync.
  • Add folders with one command: gdrive-sync.sh add-folder ~/Documents.
  • Runs every 30 minutes through a systemd user timer.
  • Skips build output and dependency folders such as node_modules, .next, build, dist, and vendor.
  • Logs locally and sends a desktop notification when a sync fails.

Install

git clone https://github.com/mteguhfh/gdrive-sync.git
cd gdrive-sync
./gdrive-sync.sh setup
./gdrive-sync.sh add-folder ~/Documents
./gdrive-sync.sh sync --dry-run
./gdrive-sync.sh install

Your data

The script runs on your own computer. It talks directly to Google Drive through rclone. It does not send files, file names, or account data to any server operated by this project.
