Privacy Policy

Last updated: 24 November 2026

This policy explains how gdrive-sync handles Google user data. gdrive-sync is a free, open-source command-line tool that runs on the user's own computer.

1. Data the tool accesses

When the user connects a Google account, gdrive-sync requests the Google Drive scope https://www.googleapis.com/auth/drive. This lets the tool read, create, update, and delete files in the Google Drive account that the user explicitly authorizes. The tool only accesses files inside the folder the user configures for backup.

2. How data is used

The tool uses Google Drive access only to copy or synchronize the user's selected local folders to Google Drive. It does not read Google Drive data for advertising, profiling, analytics, or any purpose unrelated to the user's backup.

3. Where data is processed and stored

  • All processing happens on the user's own computer.
  • Files are transferred directly from the user's computer to Google Drive through rclone.
  • The OAuth token is stored locally in the user's rclone configuration file.
  • Logs are stored locally on the user's computer and are not uploaded anywhere.
  • This project operates no server that receives, stores, or processes user files or file metadata.

4. Data sharing

We do not sell, rent, or share Google user data with third parties. Data is exchanged only between the user's computer and Google Drive, as directed by the user.

5. Retention and deletion

Files remain in the user's Google Drive until the user deletes them. The user can revoke access at any time from the Google Account permissions page or with rclone config disconnect. Removing the tool and its local configuration does not delete files already stored in Google Drive.

6. Limited use

gdrive-sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Children

The tool is not directed at children under 13 and does not knowingly collect personal information from children.

8. Changes

This policy may be updated when the tool changes. The latest version is always available at this URL.
